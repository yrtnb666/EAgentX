# UI 版内置的 26 个技能包

这些技能来自 `assets/skill_zip.zip`（上游 EAgent 的 2026-10-19 技能包），
程序启动时解压到：

```text
<工作目录>\.eagentx\skills\
```

每个技能目录里都有一个 `SKILL.md`。EAgent 系统提示词会让模型在需要时先读对应的
`SKILL.md`，再按里面的步骤调用 PowerShell、浏览器或 MCP 工具。技能本身大多是“操作说明 +
脚本模板”，不是装好即用的插件：

- 依赖本机软件或外部服务的技能（Siemens NX、ffmpeg、Cue Omni、sandbase、SkillHub、
  YYLO 等）需要先满足它们的前置条件，否则只能读说明，不能真正执行。
- Web 类技能还需要模型能访问网络，或者你已经配置了对应的 MCP / API。
- 技能不会绕过审批、权限和工具开关；鼠标/键盘仍然受“自动批准”设置控制。

## 使用建议

1. **先让模型自己查**：直接说“先看 `.eagentx\skills` 里有没有能用的技能”，模型会读
   `SKILL.md` 再决定。
2. **点名技能**：例如“用 `meeting-note-summarizer` 整理这段会议记录”，比“帮我总结”更稳。
3. **缺依赖会失败**：例如 `nx-auto-modeling` 需要本机装 NX，`video-frames` 需要 ffmpeg；
   失败时让模型先检查依赖，不要硬跑。
4. **需要 MCP 的技能**：`cue-omni-reader`、`sandbase`、`skillhub-cli`、`orca-replay` 等
   依赖对应 MCP server/CLI，没配置时只能当参考文档。
5. **安全**：`plugin-scanner` 本身是检查工具，不要把它当成“安装后自动免疫”；安装第三方
   技能前仍然要看来源和脚本内容。
